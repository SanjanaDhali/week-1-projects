# 📚 Cozy Corner Bookstore - Landing Page

## 📌 Project Overview
Cozy Corner Bookstore is a fictional business landing page designed to represent a warm, modern, and responsive bookstore website. The goal of this project is to clearly communicate services, engage users, and provide a clean contact experience.



## 🎯 Objective
To create a responsive business landing page using only HTML and CSS that works smoothly across desktop and mobile devices.


## 🧱 Features

- Responsive navigation bar with links and CTA button
- Hero section with value proposition and call-to-action buttons
- Services section displaying bookstore features using cards
- About section describing the business
- Contact form with HTML validation (no JavaScript used)
- Mobile-friendly responsive design using CSS media queries


## 📱 Responsiveness

The website is fully responsive and adapts to screen sizes below 768px:
- Navigation stacks vertically on smaller screens
- Hero section shifts from horizontal to vertical layout
- Services grid becomes a single column
- Contact form adjusts for mobile usability
