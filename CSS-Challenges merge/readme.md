# CSS Challenge Project

This project is a responsive front-end design built using HTML and CSS.  
It demonstrates core layout and animation concepts including Flexbox, CSS Grid, and CSS transitions.

---

## 📌 Project Overview

The project contains three main UI components:

### 1. Flexbox Layout (Testimonials Section)
- Built using CSS Flexbox
- Displays 3 testimonial cards in a horizontal row on desktop
- Automatically stacks vertically on smaller screens using media queries
- Includes hover effects for better user interaction

### 2. CSS Grid Layout (Dashboard Section)
- Built using CSS Grid
- Contains 6 dashboard-style cards
- Uses `repeat()` and `auto-fit` for responsive columns
- Maintains equal spacing and alignment across screen sizes

### 3. CSS Animation (Card Hover Effect)
- Simple hover animation using `transform` and `transition`
- Card lifts smoothly when hovered
- Adds subtle shadow for depth effect
